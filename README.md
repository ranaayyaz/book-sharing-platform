## 📖 About Project

A web-based community application that allows users to share and borrow physical and digital books.

## 🛠️ Technologies Used

- **Backend:** Flask (Python)
- **Database:** SQLite
- **Frontend:** HTML, CSS, Bootstrap, Jinja2
- **Authentication:** Flask-Login
- **Password Hashing:** Werkzeug

## 🚀 Features

- User Registration & Login
- Add/Edit/Delete Books (Physical & Digital)
- Borrow Request with Date/Time/Location
- Accept/Reject Requests
- Auto-return digital books after 7 days
- User Dashboard
- Admin Panel (Manage Users & Books)

## 🚀 Installing Dependencies:

## 🚀 Run the Application:
